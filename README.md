# Hangman Game

A simple text-based Hangman Game developed in Python as part of the CodeAlpha Python Programming Internship.

## Features

* Random word selection
* Maximum 6 incorrect attempts
* Win and lose conditions
* Prevents duplicate guesses
* Console-based gameplay

## Technologies Used

* Python

## How to Run

1. Open the project folder.
2. Run `hangman.py`.
3. Enter letters to guess the hidden word.
4. Win by guessing all letters before your attempts run out.
